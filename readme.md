# Turisty
Turisty est une application Web en Python pour découvrir Montréal et organiser un séjour ou une sortie selon son budget et ses intérêts. Les touristes, les nouveaux arrivants et les étudiants pourront consulter des lieux, préparer un programme et rencontrer des personnes avec qui participer à des activités.

## Getting started
You can install the required libraries from `requirements.txt` with:
```bash
pip install -r requirements.txt
```
To run turisty, you can simply run the `main.py` from inside the `src` directory:
```bash
python.exe main.py
```
If you make a clean start of the server by purging all saved data, you can use the `--reset` argument:
```bash
python.exe main.py --reset
```
*if you made changes to the schema, you will usually need to run `--reset`*
